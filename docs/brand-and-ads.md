## 一、正面回答：商标问题是否影响"接入广告"？

### 1.1 必须把三个层次拆开，它们互不决定

| 层次 | 问题本质 | 典型后果 | 与其他层的关系 |
| -------- | ------------------- | --------------------------------- | ----------------- |
| **A. 法律层** | 是否侵犯他人商标权 / 构成混淆 | 民事赔偿、责令停止使用、行政处罚（罚款）、域名被争议 | **不直接导致**广告平台拒审，但会带来 A 的独立风险 |
| **B. 平台审核层** | 广告联盟的准入与内容政策 | 审核不通过、限制广告填充、封户 | 部分平台**把知识产权与品牌一致性写进了条款**（见 1.2），因此 B 会**间接**受 A 影响 |
| **C. 落地资质层** | 主体资格、ICP 许可、内容合规、必备页面 | **完全无法上线广告** 或 无法收款 | 与 A/B 都无关，是**独立且更硬的**前置条件 |

> **一句话**：改名解决的是 A、缓解 B；但**真正决定"能不能接上广告"的是 C**。三层必须分头处理，不能混为一谈。

### 1.2 平台审核层面：主流广告联盟到底审不审"站点品牌名"？

已联网核实（检索日期 2026-09-12）。结论：**没有一家平台把"商标注册证"列为申请材料**，但**多家把"品牌与知识产权"写进了条款或软性审核项**。

| 平台 | 个人主体能否注册 | 是否把"站点品牌名"作为审核项 | 版权/知识产权要求 | 医疗健康类额外要求 | 人体解剖类内容风险 |
| ---------------- | ------------------- | -------------------------------------------------------- | ---------------------------------------------- | ---------------------------------------------- | -------------------------------------------------------------- |
| **Google AdSense** | 支持个人；付款资料国家选"中国"，走电汇 + PIN 平信验证，$100 起付。⚠️ 另有资料称大陆个人主体受限 →「**需进一步核实**」 | **是（软性）**。审核要点含 *"Original branding：站点有自己的名称、设计与编辑目的，而非模仿他人"*、*"Clear publisher identity：About/Contact/Privacy 等信任页须标明责任人"* | 政策明列 **Intellectual property abuse**（侵权、仿冒）；**Misleading representation**（**虚假暗示与他人存在关联 / 背书**）——这是与商标真正相交的两条 | YMYL 健康内容要求：**免责声明 + 可核实来源 + 作者/审校资质**；不得宣扬有害健康主张 | **中**。nudity 属 **Publisher Restrictions**（受限，非禁止）：教育/临床语境**可投放但可能只拿到很少甚至没有广告**。必须用**临床中性措辞 + 必要的解剖示意图 + 不煽情**。“年龄门槛不能把受限内容变成合格内容，医疗免责声明也不能解除限制” —— ⚠️ 具体到 3D 人体模型（含男/女参考解剖）的判定 →「**需进一步核实**」 |
| **百度联盟** | 支持个人（身份证 + 银行卡）；**ICP 备案主体须与申请主体一致** | **是（硬性要求）**。要求填写**网站名称、网站描述**且**须与实质内容相符** | **服务条款明令禁止**："侵犯他人知识产权的，包括但不限于专利权、**商标权**、著作权"；此为本项目与商标**最直接**的平台侧交点 | 涉及**新闻 / 出版 / 医疗**等特殊行业须提供相应资质证明（如《医疗器械经营许可证》）；审核对医疗类更谨慎 | **中高**。人体/解剖内容可能被人工审核归入健康类，进而被要求资质或提高审核门槛 →「**需进一步核实**」 |
| **微软广告（发布商侧）** | ❌ **通道已关闭** | — | — | — | **不适用**。原 **Monetize Now（前 pubCenter）** 停止投放 2025-09-30、产品关停 2025-10-15、**新注册关闭且官方声明不设替代品**；此前仅面向美国，国际用户只能进 waitlist。→ **"接入 bing" 在本项目语境里只能是 SEO 收录，不是广告变现渠道** |
| **国内中小联盟** | 多为个人可注册 | 通常要求网站名称与内容一致 | 一般条款含"不得侵犯他人合法权益" | 视联盟而定 | — →「**需进一步核实**」具体平台 |

**从 1.2 提炼出的三条可操作结论**

1. **"站点品牌名"确实是审核项，但不是以"商标注册证"的形式**，而是以 **品牌一致性 / 原创品牌 / 不模仿他人 / About 页责任人** 的形式存在。因此改名**能实质降低审核摩擦**。
2. **百度联盟的服务条款把"侵犯他人商标权"直接列为禁止内容** —— 这是"商标影响广告"的最硬一处：不是审核时要你交证书，而是**一旦被投诉认定侵权，可能被拒或终止合作**。
3. **医疗健康类内容有独立审核门槛**，与品牌名无关；这一点比商标更值得优先处理（见第四节）。

### 1.3 结论：改名是"硬性前置"还是"应尽早做但不阻塞"？

> **判定：属于「应尽早做、且在提交广告平台申请之前完成」，但不属于"阻塞广告接入"的技术/资质前置条件。**

拆成三种表述更精确：

| 判断维度 | 结论 | 依据 |
| ---------------------- | ----------- | ---------------------------------------------------------- |
| 是否**法律上**必须先改名才能接广告 | **否** | 商标侵权与广告投放是两套独立法律关系 |
| 是否**平台审核上**建议先改名 | **是** | 品牌一致性 / 原创品牌 / 不模仿他人 是 AdSense 明确审核项；百度联盟要求网站名称与内容相符并禁止商标侵权 |
| 是否**实际上应该先改名** | **是** | 广告申请材料（站点 URL、站点名称、About 页）会固化品牌；先改名可避免"申请后改名导致品牌与账户资料不一致"的二次沟通成本 |
| 改名是否阻塞写广告代码 | **否** | 广告代码接入不依赖品牌名；真正阻塞的是 `middleware.js` 的爬虫放行与必备页面 |
| 长期商业化 | **必须改** | MIT **不授予商标许可**；且 "Human Atlas" 与 **HuBMAP「Human Reference Atlas」** 存在混淆空间（该名词已在 `public/ATTRIBUTION.md` 中作为上游数据来源出现） |

**⚠️ 一个务实提醒**：在改名完成前，**不要把 "Human Atlas" / "人体图谱" 当作对外品牌去做宣传投放、SEO 标题或广告账户的"网站名称"**。可以先上线广告代码做技术联调，但**正式申请前必须完成品牌切换**。

### 1.4 ⚠️ 比商标更硬的四块石头（这才是"能不能落地"的关键）

| # | 阻塞项 | 现状（基于仓库事实） | 影响 | 严重度 |
| - | ---------------------- | ---------------------------------------------------------------------------------------------------------- | ------------------------------------ | --- |
| 1 | **广告爬虫被 403** | `middleware.js` 中 `const BOT_ALLOW = []`，只放行 `CN/HK/MO/TW`。Google 官方明确把"内容被限制在特定 IP 段/地区"列为 **AdSense crawler issue**，并称**可能最终停止向爬虫无法访问的页面投放广告** | AdSense 审核与投放**会失败或收不到广告**；Googlebot/Bingbot 同理被拦 → **收录也不会发生** | 🔴 高 |
| 2 | **中国大陆 ICP 经营性许可** | `middleware.js` 仅放行内地+港澳台；据《互联网信息服务管理办法》第三条，**经营性 = 通过互联网有偿提供信息**，主流解读明确把 **"网上广告（接广告盈利）"归入经营性** → 需 **ICP 经营许可证（增值电信 B25）**。个人**无法申请**（需内资公司、注册资本 ≥ ¥100 万等，详见 `monetization-options.md` 3.3） | 大陆合规挂联盟广告存在**主体门槛**；执法尺度各地不一 →「**需进一步核实**」 | 🔴 高 |
| 3 | **必备法律页面缺失** | 当前为纯静态 SPA，仅首页一个可索引 URL（`public/sitemap.xml` 已注明）；**无隐私政策 / 关于 / 联系方式 / 免责声明 / 服务条款页面** | AdSense 明确要求 Privacy Policy、About、Contact、Terms、Disclaimer 可访问；缺失会直接拒审 | 🟠 中高 |
| 4 | **Bing 变现已无通道** | 微软发布商变现产品已关停且无替代（见 1.2） | 客户诉求中的"bing"**只能做 SEO 收录**，不能作为广告渠道预期收益 | 🟠 中高 |

## 二、商标命名方案（核心交付）

### 2.1 命名的硬约束

| 约束 | 说明 | 优先级 |
| ------------------------ | ----------------------------------------------------------------------- | --- |
| **必须弃用 "Human Atlas"** | MIT 不授予商标许可；且与 HuBMAP「Human Reference Atlas」存在混淆空间 | P0 |
| **必须避开医疗暗示** | 不得被联想到诊疗 / 临床 / 诊断（NMPA 医疗器械监管红线）；名称本身不宜出现"医 / 诊 / 疗 / 康复 / 临床 / 药 / 检测"及英文 medical / clinical / diagnose / therapy / health | P0 |
| **显著性优先** | 纯描述性名称（如"3D人体图谱""人体解剖图"）显著性弱、易被驳 | P0 |
| **避开英文 `atlas` 词根** | 保留 `atlas` 等于保留与 "Human Atlas" 的近似度，反而提高混淆风险 | P0 |
| **避开已知同名 / 强关联品牌** | 例如 `somatic*`（心理治疗）、`morphia/morpho`（药企）、`trisomy`（疾病名）、`voxel`（行业通用术语） | P0 |
| **中文好念、英文好拼、可做域名** | 中文 ≤ 3 字；英文 5–9 字母、无生僻连字符 | P1 |
| **视觉不承载配色** | 黑红金是视觉规范，不要求由名称承载 | P2 |

### 2.2 ⚠️ 检索方法（**本分析无商标数据库权限，以下步骤必须由你自行执行**）

> **本分析不构成法律意见，也**没有**任何商标数据库访问权限。下述候选名均**未**做过在先权利检索，**不得**视为"可注册"或"无侵权风险"。正式注册前，建议委托**在国家知识产权局备案的商标代理机构**做检索并出具检索报告。

**A. 中国商标网（免费，官方）**

1. 打开 `https://sbj.cnipa.gov.cn/sbj/index.html` → 点击 **「商标网上查询」** → 「我接受」进入查询系统（需注册登录）。
2. 选择 **「商标近似查询」**。
3. 填入 **国际分类号**（本项目重点 **9 / 41 / 42**，见 2.5）→ 输入 **检索要素**（中文、拼音、英文**分别单独查**）→ 选择图样元素 → 查询。
4. 重点看结果中的 **「已注册」「初审公告」「无效」「驳回」** 等状态。
5. 补充渠道：**商标公告**（看初审公告期）、**商标注册审查决定文书**（看是否有高度近似被驳的先例）。

**B. WIPO Global Brand Database（免费，官方）**

- `https://branddb.wipo.int/` → 按商标文字检索 → 覆盖**马德里体系指定中国**的国际注册及其他国家在先权利，弥补单一国家数据库盲区。

**C. 检索要素必须拆分（最容易被漏的一步）**

| 检索维度 | 要查什么 |
| -------- | --------------------------------------------------------------- |
| 中文 | 品牌中文全称；**换字 / 同音 / 形近**变体（如"维体"→"维提""威体""微体"） |
| 拼音 | 全拼 + 首字母缩写（如 `WEITI` / `WT`） |
| 英文 | 全大写 / 全小写 / 首字母大写；**词根拆分**后单独查（如 `SOMA`、`META`、`VERSE`） |
| 域名 | `.cn` / `.com` 等后缀可用性；⚠️ 即使域名可注册，**在先使用并有一定影响的域名也可能构成混淆行为** |
| 类别 | 9 / 41 / 42 **逐类**查询（一类没有≠其他类也干净） |

**D. 三个必须知道的检索误区**

1. **只查相同不查近似** —— 近似也会被驳回（"鑫源"与"鑫元"属近似）。
2. **只查一个类别** —— 第 9 类干净不代表第 41 / 42 类干净。
3. **查到没有就以为万无一失** —— 存在 **1–3 个月"盲期"**（申请到录入有延迟），查询结果**仅供参考、无法律效力**。

**E. 商标注册成本与周期（已联网核实，2026-09-12）**

| 项目 | 数值 |
| ------------ | ------------------------------------------------------------ |
| 官费 | **网上申请 ¥270 / 类**（含 10 个商品/服务项，超项每个加收 ¥27）；纸质申请 ¥300 / 类 |
| 形式审查 | 约 **3–4 周**下发受理通知书（整体形式审查 1–2 个月） |
| 实质审查 | 约 **4–6 个月** |
| 初步审定公告 | **3 个月** |
| 全流程 | 顺利情况下 **约 9–12 个月** |
| 有效期 | **10 年**（期满前 12 个月可续展） |
| ⚠️ 自然人申请 | 以**自然人名义**申请需提交 **个体工商户营业执照副本 + 身份证复印件**；**无执照的纯个人一般无法以自己名义申请** |

### 4.4 广告位设计建议（**不要让广告破坏 3D 交互体验**）

> 本产品是**全屏 canvas**：底部是 `Drag to orbit` / `Drag to pan` / `Pinch to zoom` 手势区，右侧是浏览面板（Systems / Inventory），上方有 `Explode anatomy` 滑杆与相机控制，另有搜索弹层。**任何覆盖这些区域的广告都会同时损害体验并触碰"欺骗 / 误导点击"红线。**

**✅ 建议广告位（按优先级）**

| 优先级 | 位置 | 理由 | 注意 |
| --- | --------------------------------- | ------------------------------------ | ------------------------------- |
| **P0** | **页脚 / 底部信息条（窄条，非 sticky）** | 与手势区物理分离，最不打扰 | 高度控制在窄条范围；滚动到端部才出现 |
| **P1** | **加载态位**（`loadingTitle` "Preparing the anatomy" 期间） | 模型加载耗时客观存在，等待位**天然不打断操作** | 加载完成即销毁；不得延迟加载完成时间 |
| **P1** | **右侧面板内原生卡片位**（About / Systems / Source & credits 面板下方） | 属"信息浏览区"，用户主动打开，干扰最小 | 面板收起时不渲染 |
| **P2** | **移动端首屏 / 落地页插屏** | 移动端小屏比桌面更需要"先看后进"的分层 | **必须一键关闭**（第十条），且不得影响进入 3D |
| **P2** | **关于 / 来源（Source & credits）面板内** | 内容型位置，与广告语境自然 | 不得削弱 BodyParts3D 署名可见性 |

**❌ 严禁的广告位 / 形式**

- 覆盖 canvas 中央或贴合手势区的浮层、跟随指尖的 sticky 大横幅；
- 伪装成 UI 控件（按钮 / 滑杆 / 面板标题 / 相机控制）；
- 自动播放带声视频、导致布局位移（CLS）的广告；
- 关闭需两次点击、或同页反复弹出的弹窗。

**实现要点**

1. **单屏广告位 ≤ 2**；建议**先只上 1 个位**（页脚窄条）跑一段观察体验与收益，再逐步放量。
2. **类目屏蔽是硬要求**：必须在联盟后台屏蔽 **医疗 / 药品 / 医疗器械 / 保健食品 / 美容** 等类目（依据《互联网广告管理办法》第八条）。
3. **视觉规范**：广告容器用**中性灰底 + 细边框**，避免与**黑红金**主视觉抢焦点；容器角落标注"广告"。
4. **性能**：广告脚本**异步加载**，不得阻塞首屏与 canvas 首帧；建议用 `IntersectionObserver` 懒加载。
5. **爬虫放行（关键）**：`middleware.js` 需放行 **`Mediapartners-Google`**（AdSense 内容抓取）与 **`Google-Display-Ads-Bot`**；若要"谷歌 / bing 收录"，还需放行 **`Googlebot` / `Bingbot`**（当前 `BOT_ALLOW = []`，两者都会被 403）。**这是"接广告 + 做收录"共同的第一个技术动作。**
6. **`public/robots.txt`** 已 `Disallow: /models/`：该规则**不影响**广告爬虫抓取页面，但需确认 `robots.txt` 未误禁 `Mediapartners-Google`（当前无相关禁止项，✅ 无需改动，仅需在 `middleware.js` 放行）。
